Input Content Guide

This panel accepts structured input in a key-value format. You can type directly or load content from a file.

Line Format Rules

Prefix Meaning Example
# Comment (ignored by parser) # This is a comment
$ Parameter definition $input_file=/path/to/file.txt
(blank) Blank lines are ignored

Parameter Format

Parameters follow the pattern: $name=value

  • name: Parameter identifier (alphanumeric, underscore allowed)
  • value: Can be text, number, file path, or special format

Special Value Formats

Type Format Example
Color (RGBA) R,G,B,A (0-255) 255,100,50,255
Color (Hex) #RRGGBB or #RRGGBBAA #FF6432 or #FF6432FF
Font name,style,size Arial,0,14
File Path Absolute or relative path /home/user/data.txt

Font Style Values: 0=PLAIN, 1=BOLD, 2=ITALIC, 3=BOLD+ITALIC

Tabular Data

For table-like data, separate columns with Tab character.

Quick Tips

  • Double-click on a parameter line to quickly select the name or value
  • Ctrl+Click in the input area to insert a file path
  • Use the Focus button for distraction-free editing
  • Click Examples to see sample inputs for this module
