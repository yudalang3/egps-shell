Problem to Solve:

Provide a cross-platform file manager, similar to Windows File Explorer

Key Features:

1. Sidebar with Tagging Functionality: Users can place frequently accessed directories here for quick file opening.

2. Column-based File Browsing: This feature mirrors the functionality seen in MacOS and OneCommander, allowing for an intuitive multi-pane interface to navigate through files and directories.

Quick Start:

All operations are intuitive and easy to understand. Please follow the graphical user interface instructions.

Notes:

1. Double-click a folder to add a new directory column in the middle panel.

2. Right-click on blank areas, files, and folders for interactive operations.
