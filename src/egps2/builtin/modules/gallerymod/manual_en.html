This is a navigation module designed to quickly preview the features of graphical interface modules and help users find appropriate analysis modules for their data.

Key features:

Provides a mechanism for rapid preview of software modules, allowing users to browse modules according to different classification criteria.

Quick Start:

All operations are intuitive and easy to understand. Please follow the graphical user interface instructions.

Notes:

1. Double-click the buttons on the left to quickly launch modules.

2. The settings panel allows you to configure whether to display Chinese documentation: Preference -> Graphics -> Language
