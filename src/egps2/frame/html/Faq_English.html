Global Font System - Frequently Asked Questions

Version: 1.0 | Last Updated: December 7, 2025

General Questions

Q1: What is the Global Font System?

A: The Global Font System is a comprehensive font management framework introduced in eGPS v2.1.0 that allows users to customize fonts for all UI components throughout the application. It provides 27 different font types categorized into 7 groups.

Q2: How many font types can I customize?

A: You can customize 27 different font types:

  • Module Fonts (3): Module Title, Module Content, Document
  • Dialog Fonts (3): Dialog Title, Dialog Content, Dialog Button
  • Component Fonts (3): Label, Button, CheckBox
  • Input Fonts (3): TextField, TextArea, ComboBox
  • Data Display Fonts (4): Table, Table Header, List, Tree
  • Tool Fonts (2): ToolTip, ToolBar
  • Menu Fonts (2): First Level Menu, Second Level Menu
  • Tab Fonts (2): Selected Tab, Unselected Tab
  • Other Fonts (5): ProgressBar, Slider, Spinner, ScrollPane, etc.

Q3: Where can I find the font settings?

A: Navigate to File → Preference → Appearance. You'll find 8 different font setting panels organized by category.

Customization Questions

Q4: Do my font changes apply immediately?

A: Yes, when you click the Apply button in the Preference dialog, all fonts are updated immediately across the entire application.

Q5: Why does TextArea use a monospaced font by default?

A: TextArea components are designed for code editing and log viewing, where monospaced fonts provide better readability and alignment. You can change this in Preference if needed.

Technical Questions

Q6: Will my font settings persist after restarting eGPS?

A: Yes, all font settings are automatically saved to ~/.egps/json/defaultGlobalProperties.json when you click Apply or OK.

Q7: What happens if my selected font is not available on another computer?

A: Java's font system will automatically substitute a similar available font. Use widely available fonts like Microsoft YaHei UI, Arial, or SimSun for best compatibility.

Developer Questions

Q8: How do I use global fonts in my module?

A: Access fonts through the LaunchProperty class:

import egps2.UnifiedAccessPoint;
import egps2.LaunchProperty;

LaunchProperty lp = UnifiedAccessPoint.getLaunchProperty();
JLabel label = new JLabel("Hello");
label.setFont(lp.getLabelFont());

For detailed guidance: See docs/global_preference/how_to_use_global_preference.md

Q9: Do I need to manually set fonts for all components?

A: No! Standard Swing components automatically use global fonts via UIManager. You only need to manually set fonts when:

  • Creating custom components
  • Overriding default fonts for specific use cases
  • Drawing text directly using Graphics

Q10: Which font should I use for my module's title?

A: Use semantic font selection:

  • Module titles: getDefaultTitleFont()
  • Module content: getDefaultFont()
  • Dialog titles: getDialogTitleFont()
  • Data tables: getTableFont()
  • Code/logs: getTextAreaFont() (monospaced)

Troubleshooting

Q11: Some dialogs still show wrong fonts. Why?

A: This can happen if:

  1. Cached components: Try restarting eGPS
  2. Hardcoded fonts: Some modules may use hardcoded fonts (please report as bug)
  3. Third-party libraries: External libraries may not respect UIManager settings

Q12: Can I export/import my font settings?

A: Yes, indirectly. Your settings are stored in ~/.egps/json/defaultGlobalProperties.json. You can:

  • Copy this file to backup your settings
  • Share it with colleagues for consistent UI
  • Restore it by replacing the file and restarting eGPS

Note: Make sure eGPS is closed before manually editing this file.
