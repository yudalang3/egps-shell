全局字体系统 - 常见问题解答

版本：1.0 | 最后更新：2025年12月7日

基础问题

问题1：什么是全局字体系统？

答：全局字体系统是eGPS v2.1.0引入的一个综合字体管理框架，允许用户自定义整个应用程序中所有UI组件的字体。它提供了27种不同的字体类型，分为7个类别。

问题2：我可以自定义多少种字体类型？

答：您可以自定义27种不同的字体类型：

  • 模块字体 (3种)：模块标题、模块内容、文档
  • 对话框字体 (3种)：对话框标题、对话框内容、对话框按钮
  • 基础组件字体 (3种)：标签、按钮、复选框
  • 输入组件字体 (3种)：文本框、文本区域、下拉框
  • 数据展示字体 (4种)：表格、表格表头、列表、树形控件
  • 工具组件字体 (2种)：工具提示、工具栏
  • 菜单字体 (2种)：一级菜单、二级菜单
  • 标签页字体 (2种)：选中的标签页、未选中的标签页
  • 其他字体 (5种)：进度条、滑块、微调器、滚动面板等

问题3：在哪里可以找到字体设置？

答：导航至 File → Preference → Appearance。您会看到按类别组织的8个不同的字体设置面板。

自定义问题

问题4：我的字体更改会立即生效吗？

答：是的，当您在"Preference"对话框中点击Apply按钮时，所有字体会立即在整个应用程序中更新。

问题5：为什么TextArea默认使用等宽字体？

答：TextArea组件主要用于代码编辑和日志查看，等宽字体能提供更好的可读性和对齐效果。如果需要，您可以在Preference中更改。

技术问题

问题6：重启eGPS后，我的字体设置会保留吗？

答：是的，当您点击Apply或OK时，所有字体设置都会自动保存到~/.egps/json/defaultGlobalProperties.json。

问题7：如果我选择的字体在另一台电脑上不可用会怎样？

答：Java的字体系统会自动替换为相似的可用字体。建议使用广泛可用的字体，如Microsoft YaHei UI、Arial或SimSun以获得最佳兼容性。

开发者问题

问题8：我正在开发模块，如何使用全局字体？

答：通过LaunchProperty类访问字体：

import egps2.UnifiedAccessPoint;
import egps2.LaunchProperty;

LaunchProperty lp = UnifiedAccessPoint.getLaunchProperty();
JLabel label = new JLabel("你好");
label.setFont(lp.getLabelFont());

详细指导请参见：docs/global_preference/how_to_use_global_preference.md

问题9：我需要手动为所有组件设置字体吗？

答：不需要！标准Swing组件会通过UIManager自动使用全局字体。您只需要在以下情况下手动设置字体：

  • 创建自定义组件
  • 针对特定用例覆盖默认字体
  • 使用Graphics直接绘制文本

问题10：我的模块标题应该使用哪个字体？

答：使用语义化的字体选择：

  • 模块标题：getDefaultTitleFont()
  • 模块内容：getDefaultFont()
  • 对话框标题：getDialogTitleFont()
  • 数据表格：getTableFont()
  • 代码/日志：getTextAreaFont()（等宽）

故障排除

问题11：更改设置后，某些对话框仍显示错误的字体，为什么？

答：这可能是由于：

  1. 缓存的组件：尝试重启eGPS
  2. 硬编码字体：某些模块可能使用硬编码字体（请报告为bug）
  3. 第三方库：外部库可能不遵循UIManager设置

问题12：我可以导出/导入字体设置吗？

答：可以，间接方式。您的字体设置存储在~/.egps/json/defaultGlobalProperties.json中。您可以：

  • 复制此文件以备份设置
  • 与同事共享以保持UI一致
  • 通过替换文件并重启eGPS来恢复设置

注意：在手动编辑此文件之前，请确保eGPS已关闭。
